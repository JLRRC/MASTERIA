# MASTERIA

Repositorio de materiales del Máster en Inteligencia Artificial y Robótica (MIAR).

## Contenido

- **03MIAR Algoritmos de Optimización**: Notebooks y materiales sobre algoritmos de optimización
- **05MIAR_Aprendizaje_Supervisado**: Notebooks y materiales sobre aprendizaje supervisado

## Uso de GitHub Copilot

Para aprender a usar GitHub Copilot con VSCode en este proyecto, consulta la [Guía de Copilot](COPILOT_GUIDE.md).

### Inicio Rápido con Copilot

1. Instala [Visual Studio Code](https://code.visualstudio.com/)
2. Instala las extensiones recomendadas (VSCode te las sugerirá al abrir el proyecto)
3. Sigue la [guía completa de Copilot](COPILOT_GUIDE.md) para configuración detallada
